# Ukrainian Outages для Home Assistant

Графіки відключень для України за областю, оператором і чергою. У бічному меню Home Assistant з'являється панель **Графіки світла України** з таблицею всіх опублікованих черг, виділенням вибраної черги та відліком до найближчого підтвердженого інтервалу.

## Встановлення через HACS

Потрібен Home Assistant Core 2024.11.0 або новіший.

1. У HACS відкрийте меню з трьома крапками, виберіть **Custom repositories** і додайте `https://github.com/adeptoleg/ha-uktainian-outages` як **Integration**.
2. Завантажте **Ukrainian Outages** і перезапустіть Home Assistant.
3. Відкрийте **Налаштування → Пристрої та служби → Додати інтеграцію → Ukrainian Outages**.
4. Виберіть **область або місто**, **оператора**, якщо у регіоні їх кілька, і **чергу**. Можна додати кілька черг у різних областях. Для кожної з них створюється окремий запис.
5. Відкрийте **Графіки світла України** в бічному меню. Якщо панель ще не з'явилась у відкритій вкладці, оновіть її.

Ручне встановлення також можливе. Скопіюйте каталог `custom_components/adept_ua_outages` у `custom_components` Home Assistant і перезапустіть систему.

## Що видно на панелі

- Сьогоднішній і завтрашній графік, час за Києвом та риска **Зараз**, до якої можна повернутися одним натисканням.
- Компактний список інтервалів вибраної черги з точністю опублікованих даних. У таблиці підтверджені й можливі відключення позначені окремо. Штрихова клітинка може позначати підтверджене відключення в частині півгодини.
- Над шкалою позначаються ніч, цивільні сутінки й день для координат із **Налаштування → Система → Загальне**. Смуга використовує одну локацію Home Assistant для всіх вибраних областей. Без заданих координат вона прихована.
- Поточний плановий стан, наступний початок і відновлення за графіком. Якщо інтервал не має відомого кінця, відлік до відновлення приховано.
- Фактичний стан мережі, якщо в налаштуваннях запису вибрано `binary_sensor` інвертора або іншого локального джерела. Втрата зв'язку з датчиком відображається окремо.
- Посилання на джерело. Якщо оператор публікує лише зображення й джерело повертає його адресу, панель додатково показує посилання на нього.

На телефоні сьогоднішня шкала відкривається біля поточного часу. Стовпчик черг залишається зліва під час горизонтального гортання.

### Картка для окремої панелі

```yaml
type: custom:adept-ua-outages-card
```

Якщо налаштовано кілька черг, додайте `entity` з ідентифікатором сенсора стану потрібного запису.

## Сутності й автоматизації

| Сутність або подія | Призначення |
| --- | --- |
| Календар | Підтверджені інтервали відключення вибраної черги. |
| Стан за графіком | Заплановане або можливе відключення, аварійний режим, відсутність опублікованих даних. |
| Наступне відключення та відновлення | Часові сенсори для автоматизацій за графіком. |
| Мережа | Фактична наявність живлення. Для автоматики використовуйте переходи `on` → `off` і `off` → `on`, щоб втрата зв’язку не запускала пристрій. |
| `adept_ua_outages_schedule_changed` | Публікація, зміна або зняття графіка після першого зчитування. Дані події містять `region`, `operator`, `queue` і `dates`. |

Графік оновлюється під час запуску і далі приблизно раз на 10 хвилин. Записи одного оператора спільно використовують короткочасний локальний кеш. Годинник і відлік оновлюються щохвилини в браузері.

## Покриття і джерела

У налаштуваннях доступні всі **24 області, АР Крим, Київ і Севастополь**. Для **22 територій** є налаштовані джерела. Наявність графіка на сьогодні й завтра залежить від публікацій операторів. Для Донецької, Луганської, Херсонської областей, АР Крим і Севастополя автоматичних погодинних даних у цій версії немає. Їх можна вибрати для показу статусу джерела та підключення локального датчика мережі.

- [OE_OUTAGE_DATA](https://github.com/yaroslav2901/OE_OUTAGE_DATA) надає початкові JSON-графіки для 12 областей.
- [gpv-voe-vinnytsia](https://github.com/vn-progr/gpv-voe-vinnytsia) надає публічний JSON для Вінницької області.
- Для інших підтримуваних операторів і як резерв за наявності групового джерела використовується бібліотека [ukraine-energy-monitor v0.6.1](https://github.com/fastiuk/ukraine-energy-monitor/tree/v0.6.1). Її копія в `ua_outages` зберігає [ліцензію MIT](custom_components/adept_ua_outages/ua_outages/LICENSE).

Порожні чи недоступні дані не вважаються відсутністю відключень. Графік є планом. Визначення фактичної наявності живлення потребує локального датчика.
